# Automation E2E & API Tests with Cypress

> Repositório de automação de testes para APIs e interface de usuário (UI), proporcionando cobertura completa para aplicações fullstack.

## 📦 Pré-requisitos

Antes de começar, certifique-se de ter instalado em sua máquina:
- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/)
- Um editor de código, como o [VSCode](https://code.visualstudio.com/)

## 🗂 Estrutura do projeto

```text
Automation-E2E-API-Tests-Cypress/
  ├─ cypress/
  │   ├─ e2e/          # Casos de teste E2E e API
  │   ├─ fixtures/     # Massa de dados para os testes
  │   └─ support/      # Comandos customizados e configurações
  ├─ results/          # Relatórios de execução
  ├─ cypress.config.js # Configurações globais do Cypress
  ├─ package.json      # Dependências e scripts
  └─ package-lock.json

```

## ⚙️ Configuração e Instalação

1. Clone o repositório:
```bash
git clone [https://github.com/GalileoGuilherme/Automation-E2E-API-Tests-Cypress.git](https://github.com/GalileoGuilherme/Automation-E2E-API-Tests-Cypress.git)

```


2. Acesse a pasta do projeto:
```bash
cd Automation-E2E-API-Tests-Cypress

```


3. Instale as dependências:
```bash
npm install

```



## 🚀 Scripts NPM disponíveis

```bash
# Abrir o Cypress em modo interativo
npx cypress open

# Executar todos os testes no modo headless
npm run cypress:run

```

## 📌 Principais Tecnologias e Ferramentas

* **Cypress** (Versão 13.15.0)
* **cypress-plugin-api** para validações de backend
* **Prisma** para manipulação de banco de dados
* **Node.js**
* Padrão **Page Object Model (POM)** e integrações de **CI/CD**

## ⚡ Objetivo

Garantir a alta qualidade e confiabilidade de aplicações fullstack através de uma estratégia robusta de testes end-to-end (E2E), testes de integração e validação de APIs RESTful.
